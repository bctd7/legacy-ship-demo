# Legacy Godot demo snapshot

This is a clean source and runtime-asset snapshot of the former project, not its Git history and not the new Ancient Ship Joinery game.

Open `project.godot` using Godot 4.7.2. The configured main entry is `scenes/workshop.tscn`; the integrated flow is `levels/integrated_demo.tscn` and the boat demo is `content/quanzhou_boat/demo.tscn`.

Model `.glb` files, runtime illustrations, scripts, scenes, UID sidecars and import settings are retained. Godot regenerates `.godot/` on first import.

Credentials, local private configuration, environment files, PDFs, source/history ZIPs, generated evidence, receipts, caches and logs are omitted. Two local image-service tests were quarantined because they matched credential-like patterns; their matched text was not published. The image-service private configuration loader is also omitted, so that optional Python service requires a separately configured implementation before use. The offline Godot game and stored art do not require API credentials.

User-specific home paths and the local Git email were replaced with placeholders in the uploaded text snapshot. Existing documentation may describe earlier project states; no claim of exact historical reconstruction is made.
