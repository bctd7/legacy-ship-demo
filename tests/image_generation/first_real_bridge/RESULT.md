## 目前能确认与不能确认的原因

本机服务当前对上游异常统一返回 `upstream_outcome_unknown`，没有透出上游 HTTP 状态、官方错误码或请求 ID。因此不能从这次 502 判断是模型开通/权限、请求参数、TLS/网络、上游服务还是响应解析问题；不能把猜测当作错误根因，也不能据此安全地自动重试。

后续应先离线补齐只返回上游状态/官方错误码/请求 ID 的诊断，保持秘密、提示词和上游原始错误消息不入日志；是否重启并重新由用户输入 Key、是否再次调用，都应在明确错误与额度后再协调。本轮没有实施这些更改，用户已配置的服务没有被破坏。
