## 3. 历史展示边界

泉州湾后渚宋代海船可支持讨论中国古代海船的榫合结构，但榫卯不是其唯一连接和密封手段，不得宣称整船无钉。出水残体不完整，展示完整船形或上部结构时，应区分实物依据与研究复原。游戏可聚焦代表性节点，但不能把局部操作范围误写为全船真实结构范围。

以上依据见闽南文化生态保护区[《后渚港宋代海船》](https://www.mnwhstq.com/szzy/qzwszlqwk/201608/t20160816_106901.htm)及泉州市政府[《“文物会说话”讲述泉州向海而兴的故事》](https://www.quanzhou.gov.cn/zfb/xxgk/zfxxgkzl/qzdt/qzyw/202402/t20240204_3002556.htm)。

## 4. 后续素材验收要点

- **许可**：权属清楚，确认展览、交互使用、修改与交付范围；公开展示不等于允许复用。
- **结构拆分**：内部关键构件可独立显示和控制，不能仅有外壳或舱内摆设。
- **接头几何**：榫头、榫眼及接触面真实存在，能承受局部放大观察，并有史料或研究依据。
- **装配顺序**：构件连接关系与展示顺序可核实；教学顺序若有调整，需说明其与历史工艺的关系。
- **格式**：确认能导出 glTF/GLB 等通用交换格式，保留构件层级、尺度、方向、材质与贴图；到 Godot 的导入效果另行验证。
- **设备性能**：检查几何量、贴图体积、材质复杂度与加载开销，并在最终设备测试；不得以网页预览替代验收。

若现有资产不足，先列明缺失构件和影响，再讨论范围调整或专业补充制作；不默认由用户自行完成专业建模。本阶段不购买、不联系作者、不下载或制作模型。
