# 当前桥工程架构

范围为鲁班桥单机验收版。当前分层已整理，不继续扩建框架；船和 LAN 均未接入。

## 文件职责

| 文件或目录 | 职责 |
| --- | --- |
| `app/bridge_workshop.gd` | 模块接线、选择及反馈协调；仅 `_refresh_interaction()` 计算交互可用状态 |
| `app/workshop_stage.gd` | 环境、地面、灯光与相机创建；不判断装配状态 |
| `ui/workshop_ui.gd` | 布局、托盘、菜单及确认层，发出意图，不直接写装配状态 |
| `interaction/drag_interaction.gd` | 拾取、手势、独立候选、滞回与释放请求 |
| `interaction/drag_contract.gd` | 复制来源上下文并组装请求；[字段约定](../interaction/CONTRACT.md) |
| `session/local_session.gd` | 权威槽位占用、动作、请求版本、动画票据、提交、取消、重置与恢复 |
| `content/luban_bridge/bridge_rules.gd` | 此模型的兼容、占用、依赖、库存及手势校验 |
| `content/luban_bridge/bridge_presenter.gd` | 来源网格、单件跟手朝向、原路径动画、辅助显示清理 |
| `content/luban_bridge/content.json`、`assets/`、`reference/` | 稳定ID、类型数量、槽位、已核对姿态、原路径及原始资源证据 |
| `tests/` | 六套当前有限检查、顺序运行入口、旧测试原文归档 |

会话的内部动作是 `_pending`；外部使用 `is_busy()`、`is_action_pending()`、`pending_ticket()` 查询，不读取提交字典内部。按钮与拖动均进入同一会话校验和最终提交路径。

## 状态与拖动边界

权威状态是 `placements: slot_id -> inventory_type_id` 与已完成动作。剩余库存由初始数量减去占用派生，不另存第二份可变计数。动画完成并核对票据后才提交；取消与重置使旧票据失效。

`selection.item_id` 是托盘项，不是目标网格名；按下时复制到 `drag_source`，本次释放或取消前保持身份。`hover_target` 独立保存候选，不能覆盖来源。`slot.anchor_m`保留最终参考点；`trigger_points_m`给出一个槽位的多个可触发位置，`marker_points_m`控制显示点，`hover_target.trigger_point_m/trigger_index`记录本次命中的触发点。同一槽位不同触发点不产生新库存或新占用。放置请求分别携带来源 `inventory_type_id` 和目标 `slot_id`。

呈现器按住时只用固定来源预览，绕几何中心平滑调整旋转，位置直接跟随鼠标平面；不引用安装起点来移动拖动预览。桥面来源是共同板面代理，其他构件仍用来源网格。合法释放后才使用对应真实构件、原 `path.from_m -> path.to_m` 和原时长执行安装，不缩短或重建路线。

`inventory_families`只聚合操作类别：桥面卡`deck`汇总三种实际库存，`target_options`按目标所需类型开放五个合法空槽。请求保持来源`deck`，内容规则在校验时将目标解析为实际库存ID，提交与快照始终保存原三种ID。托盘缩略图和拖动共用90×134×7.5 mm板面；目标朝向依据原模型作者的40/20/0/-20/-40度板面姿态。只有松手验证通过后才使用原完整托臂支脚。规则版本仍为`inventory_slots_2`，已有快照不需要因操作卡合并再次迁移；会话与通用输入模块未增加桥面分支。

schema 3 快照深拷贝槽位映射、动作、内容/规则版本和修订号；恢复校验兼容、数量、依赖和提前撤除。schema 1、2迁移仍保留。本轮库存规则更新到`inventory_slots_2`，模型规则依据`legacy_inventory_migrations`将旧`inventory_slots_1`中的后中梁映射为共享中梁，并先校验它在旧规则下的合法槽位。迁移副本后仍走统一数量/依赖校验，不修改调用者快照。没有拆迁移器或删除旧存档入口。

## 模型与路径证据

两个原 v2 GLB 保持原始字节。模型是照片启发的教学改型，不是历史原物测绘；桥面托臂和支脚属于正式几何，不因清理辅助而删除。

- [兼容类型证据](../content/luban_bridge/reference/compatibility_certificate.json)：7类、20件；前后中梁已核实等价并合并。证据包含正旋转、表面覆盖、作者几何与实际顶点对应；部分桥面按相同包络和接触位置核对，不代表全部三角网格逐点一致。
- [中梁全部三角面等价证据](../content/luban_bridge/reference/centre_beam_equivalence.json)：相同205.48×16×13 mm尺寸和三个槽口，正旋转行列式+1、平移约210 mm，双向全部三角面覆盖通过，保守表面带界1微米，采样偏差约0.000015 mm。752/760三角面的剖分差异不再以顶点集合最近距离误判为形状差异。沿梁五个实际有效段点加旧参考点，半径仍36 mm。
- [桥面实际几何与触发点](../content/luban_bridge/reference/placement_geometry_certificate.json)：面板尺寸相同，但托臂横长163/193/223 mm、支脚中心距150/180/210 mm，内部维持三种规格并由统一操作卡选择；01/04与02/05实际表面采样偏差约0.000043 mm。桥面中心和圆杆对称两端直接取自世界坐标GLB，半径仍36 mm。反侧圆杆只新增触发，仍用原负Z安装路径。
- [同组换序证据](../content/luban_bridge/reference/free_order_certificate.json)：65对完整路径扫掠包围盒分离，仍保留跨组依赖，不声明全部排列安全。
- [最后三段补核](../content/luban_bridge/reference/remaining_paths_certificate.json)：原 `path_validation.json` 只保存至18段，原文件保留，后3段另有1014对覆盖检查记录。
- [反向姿态采样复核](validation/pose-geometry-verification.json)：直接读取世界坐标GLB，反向端梁双向三角顶点/重心到表面的最大采样误差约6.05e-8 m，旋转行列式为正；采样不是完整解析等价证明。

以上属于理想几何和受控运动学证据，不是制造公差、重力自承或承载认证。本轮没有重跑 Blender 大规模验算或改网格。

## 扩展边界

当前保留轻量 Dictionary 请求，但集中字段约定和构造入口；加入第二内容包或联机前再按实际需求强化类型，不先造复杂框架。旧测试原文在 `tests/archive_before_inventory/`，当前入口与历史日志明确分开。

当前开发验证为 Windows / Godot 4.7.2 / 兼容性渲染，实体鼠标、触摸屏、多点输入及其他设备未完成正式验收。船模型许可、可拆结构和历史依据仍是独立依赖，不能以桥测试替代。先等待用户验收桥，再决定船接入。
