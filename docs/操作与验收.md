# 鲁班桥操作与验收

当前仍待用户最终验收。本页描述单件跟手预览版本，取代历史多投影方案。

## 启动与装配

停止旧游戏，在原项目按 **F5** 重开，或使用本轮新开的窗口。顶部可复位视角、查看提示；鼠标右键旋转、滚轮缩放，也可打开“旋转”后在空白展示区左拖。“更多”内有观察完整模型和需确认的重置。

点击托盘只选中，按住后拖向亮起的兼容空槽。拿起后来源身份和预览网格锁定，只有一个来源预览；网格中心跟随鼠标所在固定拖动平面。桥面预览只含共同板面，其他构件仍是来源实物网格。合法候选只平滑改变朝向，不把位置移到高入口，也没有额外落位幽灵或高处投影。

候选附近保留少量退出缓冲以减少闪跳；视觉缓冲不扩大提交半径。离开范围或经过错误、占用槽时，不更换规格，恢复拿起朝向。**松手校验通过以后**，才播放原完整高入口装入动画；从高处落入是保留行为，不是按住期间的预览跳高。临时25 mm末段试验未交付，原路径与时长不变。

库存仅在合法动画完成后减少一次。错误、不兼容、已占槽、缺少前置或陈旧请求均不安装、不消耗库存。

## 类型、顺序与撤除

| 库存类型 | 数量 |
| --- | ---: |
| 端部梁 | 4 |
| 侧段梁 | 4 |
| 中梁（前后共用） | 2 |
| 横向圆杆 | 5 |
| 桥面（统一操作卡） | 5 |

桥面托盘只显示一张“桥面×5”，其剩余数量由五个桥面槽的实际占用推算。玩家可拖到任一合法桥面空槽，无需选择支脚距。拖动时只显示共同的90×134×7.5 mm板面；目标只改变朝向，合法松手后系统才选用对应完整构件及原安装动画。已装17/20且桥面01、04已占用时，仍显示同一张“桥面×3”，其余三处均可继续安装。

下部实际结构仍保留：01/04托臂总长163 mm、支脚中心距150 mm；02/05为193/180 mm；03为223/210 mm。合并的是操作类别，不能据此宣称五件完整构件等形。内部仍有三种库存规格，快照继续存实际规格；01↔04、02↔05的刚体互换关系保留，表面采样偏差约0.000043 mm。原GLB、装配路径与时长均未改动。

放桥面时可瞄准实际桥面中心的亮点。最终槽位ID不变，实际中心作为新增触发点；旧支脚参考点保留兼容，仍是36 mm范围，不靠扩大阈值修补。

圆柱两端与两侧接合点对称地触发同一个槽位，一端装入后另一端不能再消耗一次。**两侧触发仍播放同一条原已验证的负Z侧装入动画**；反向装入路径未验证，未启用，不承诺从鼠标所在侧实际插入。

同规格可放任意兼容空槽。同组可换序，跨组仍保留装齐梁后装圆杆、装齐圆杆后装桥面的保守依赖。前后中梁本轮已通过实际网格双向全部三角面覆盖核对，可平移约210 mm重合，无需镜像或缩放，现合并为中梁×2。两者尺寸约205.48×16×13 mm，三个槽口形状和位置一致。旧检查因三角剖分不同（752/760三角面）误把最近顶点距离当成形状差异；原未确定记录保留在证据历史中。

中梁触发现在覆盖实际网格中心及沿梁五个有效段点，保留旧参考点和36 mm半径；前后空槽共用两件库存。邻槽仍需对应规格，已占槽不能重复安装。旧规则schema3快照会将原“后中梁”类型安全迁移为中梁，schema1/2仍支持。

初始已有两个基座；界面统计 20 个可装正式件，最后共有 22 个正式网格。蓝色托柱与示意吊索是操作辅助，不是正式桥构件。

20 件装齐后，左侧“撤除辅助支撑”可用；也可从辅助托盘或蓝色支撑轻轻斜向下拖，变绿后松手。未装齐时按钮禁用并说明缺几件。撤除中可再点“取消撤除”或按 Esc；完成后辅助、提示与预览清理。观察返回保留进度，确认重置恢复全部库存。

当前槽位半径 36 mm；辅助拾取包围外扩 12 mm，向下阈值 18 mm、允许侧偏 120 mm。这些是米制交互容差，不是模型制造公差或屏幕像素承诺。

## 手动验收清单

1. 按住端梁扫过同向、反向、错误和已占槽：只见手中这一件，位置跟手，合法目标只调整朝向。
2. 移出再进入、经过其他托盘卡片，确认不换来源、不出现高处副本。
3. 试中梁的前后空槽、中心与靠近两端处；同一卡片应能连续放两件，邻近侧梁槽和已占槽不应误占。
4. 用同一“桥面”卡连续放到五处空位，检查按住时只有共同板面、松手后出现对应完整托臂支脚；17/20时应显示“桥面×3”。已占槽不得重复安装。从圆柱两端分别触发，另一端重复放置应拒绝。
5. 合法松手后才从原高处装入；错误松手不安装、不扣库存。连续拖下一件也正常。
6. 试 Esc 取消、观察返回和确认重置，检查无残留预览或锁住选择。
7. 装齐后分别试按钮撤除、取消撤除和斜拖撤除；完成后只保留正式桥体。

检查通过 `Input.parse_input_event` 派发 Godot 鼠标事件；不是操作实体鼠标，不是触摸屏、多点输入或其他设备验收。用户仍需判断真实操作手感。

历史运行曾有一次末段斜拖、一次按钮注入未触发；加入诊断后复跑通过，根因尚未确定。原失败与诊断日志保留于 `validation/`，当前回归通过不能据此声称那些事件差异已定位或实体设备已通过。

桥为教学改型；不模拟或认证重力自承、摩擦自锁、材料强度或承载能力。船、LAN、团队称号与二维码分享未接入；未创建或上传 GitHub 仓库。桥通过用户验收后再决定下一阶段。

本轮复现记录见 [修复前触发记录](validation/surface-targets-before.log)：桥面原参考点在单侧支脚，距实际中心约82–110 mm，附近错误候选会抢占；第1圆杆旧点距两端约52.5/202.5 mm。已将触发位置与最终槽位分开，并在6像素重叠邻域优先可用兼容候选；权威判定仍按对应触发点36 mm范围、规格和依赖校验。

中梁修改前记录见 [原触发复现](validation/centre-targets-before.log)：可见中心距原小偏点约45.8 mm，合理边缘约120.3 mm，因而中心/边缘会被附近圆杆或侧梁候选抢占。本轮增加有效段触发，没有改动安装路径或仅靠扩大半径。
