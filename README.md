# 木作装配互动｜鲁班桥验收版

当前是 Godot 单机桥装配体验，仍待用户最终验收。工程目录和应用名沿用“古船榫卯互动”，但船内容、LAN、团队称号与二维码分享尚未接入；未创建或上传 GitHub 仓库。

## 运行

用已安装的 Godot 打开 [project.godot](project.godot)，停止旧游戏后按 **F5**。主场景为 `scenes/workshop.tscn`。当前开发环境为 Godot 4.7.2、兼容性渲染；不代表其他设备已兼容。

## 当前操作

从下方托盘按住一个库存类型拖动。拖动中只显示这一件，中心跟随鼠标平面；靠近合法兼容空槽时平滑预览目标朝向。**松手校验通过后**才播放原高处装入动画，动画结束再扣库存。点击只选中；错误或已占槽不会安装。

前后中梁已核实同形，合并“中梁×2”，前后空槽可互换；中心及沿梁有效段均可触发。桥面统一为一张“桥面×5”操作卡，数量按未占用桥面槽汇总；拖动时仅显示共同板面，合法松手后按目标选择原托臂和支脚规格，再播放原完整安装动画。游客无需选择脚距，原三种完整桥面结构保持不变。圆柱两端可触发同一槽位，仍由系统按既定方向装入。

同组可选先后，仍保留“装齐梁 → 圆杆 → 桥面 → 撤辅助”的依赖。装齐 20 个可装件后，可点击撤除按钮或斜向下拖动蓝色辅助；完成态共有 22 个正式网格。
