## 当前镜头与钉固修复

拖动期间主镜头保持不动。有效松手后，同一完整组件停在接口近旁；关键步骤沿用户当前yaw/pitch连续靠近同一原船接口，停稳0.45秒，再演示贴合/固定，最后平滑返回进入前的焦点、距离和方向。自动流程不再加载v3局部GLB、不隐藏整船换画面、不作世界AABB硬裁切；只有挡在观察射线前的既有木件可平滑渐隐，所持组件保持实体。v3扩展仍由「单独观察」明确选择进入，不冒充原船接口。

`config/cameras.json.assembly_director` 独立配置关键组、停留与往返时间。艏斜接、左内板、主桅座、艏柱梁及艉舵保留关键观察；普通重复件不强制拉近。近景内手动旋转/缩放会保留观察；点击返回平滑回到进入前视角。返回途中按住下一张可装卡片会停止返回，保持按下时镜头开始真实拖动；撤回、重置与退出立即取消旧回调并清理临时资源。

用户钉子截图已通过Library取到本地并查看真实像素，身份记录在 `evidence/camera_continuity/screenshot_provenance.json`。除透视覆盖层错误外，实际源几何还存在外侧钉杆最多约6.8mm的离面段。现在根据原GLB木板三角面离线拟合384对头/杆，成对沿原钉轴平移到木面：外侧杆投影控制在0.1mm模型容差，所有钉头仍有可见几何。**这是本轮对原源节点最终位置的明确例外**：只调整768个钉子节点的运行时平移，原GLB、网格、尺度、轴向及木件位置不改；卡片、携带和最终安装共用修正后的节点位置，不隐藏整组紧固件。

`config/nail_seating.json` 保存每对头/杆、真实木面命中、原离面量与位移；`fit_nail_seating.py` 是单线程、无渲染的开发期生成工具，产品运行无需Python。演示用同一源Mesh、正常深度遮挡，行程为源钉长度的80%，结束后回到贴面目标并移除临时副本，保留全部原头/杆网格。钉子穿出内面的形态、历史钉固工法和整船强度不据此认证。

## 操作

- 启动即进入可操作的装配视图，第一件中央龙骨的固定金色轮廓和落点文字从开始就可见；「整船查看」可查看全部59组/1286网格。右键旋转、滚轮缩放。
- 28 张完整局部组件缩略图覆盖全部源网格；○ 表示当前可装配，✓ 表示已装配。单击只选取，超过拖动阈值才显示携带物；拖到对应连接点的圆标并松手才启动安装，范围外释放与未满足前序条件均不安装。
- 拖动时携带该卡片对应的完整真实网格组，方向和尺度保持源模型最终姿态；进入有效区时平滑对齐最终位置。有效释放后镜头定位真实连接处，再播放短斜接靠合、直榫入卯、板列原位建造、木件就位后钉入、水平入舵或帆索分组展开。板材、帆索未被当作整块刚体穿入。
- 「撤回一步」移除最近一次装配；「重置装配」清空进度、历史并复位镜头。整船查看与装配视图可随时切换，查看不会自动完成任务。
- 选择榫卯后点击「打开所选榫卯」。滑杆或「分离 / 合拢」显示真实两件模型接触面；右键与滚轮仍可操作。返回整船保留原视角和装配进度；Esc 可取消拖动或离开近景。

## 内容边界

模型均来自用户交付的三个真实资源包，原 ZIP、源装配清单、局部位置说明和 SHA-256 / Library 身份记录放在 `reference/`。未使用视频充当模型，也未使用 v4 候选。完整几何、拓扑、源装配位置保留；本轮不减模。

源 GLB 没有包含 Blender 程序木材的颜色/纹理。当前按已验收桥统一展陈画风：象牙白面板、相同字体、红棕木件和展台光照。`wood.gdshader` 使用桥的红棕木纹逻辑并增加包内局部截取/建造显示参数；原交付配色仍保存在 `config/materials.json`。显示风格发生有意统一，完整几何未改。

整船中的甲板、帆索、舵装含展示复原/假设构件。桅脚直榫、柱梁方榫是 v3 的互动扩展，**非考古原件复原**，近景持续显示此说明。龙骨、平接、搭接为原模型局部裁切；板材接缝需要紧固、密封，并非都能自锁。近景的分离用于观察接触面，不宣称演示了经过碰撞验证的真实施工路线。交付局部本身的切面和边缘几何未经重建或美化。

## 包结构与未来接入

- `assets/`：原整船与 v3 局部 GLB；`reference/`：交付原包及可追溯记录。
- `config/assembly.json`：13 组映射、依赖、连接锚点、吸附半径、真实预览件、短入位方向、逐组镜头与来源说明。原模型变换仍是最终位置，无通用代码中的船名分支。
- `config/cameras.json`：整船与独立接头浏览镜头、分离方向；步骤连接镜头单独位于 assembly.json.lesson，`boat_camera.gd` 只扩展已有旋转相机的船尺度缩放范围。
- `boat_play.gd`：船专用状态与呈现器，复用只读 `interaction/drag_interaction.gd` 和来源/释放分离契约。
- `stage_adapter.gd`：继承既有 `levels/stage.gd`，提供 `enter_stage / exit_stage / stage_result`；全部合法装配才报告 completed，payload 含独立快照。
- `model.gd` 的 `descriptor()` 可交给现有通用 model 阶段。当前未把它写入任何关卡，未改变桥→绘画流程。后续若要进入绘画，另提供正式透明 2D `drawing_asset`；本包没有把实时 3D 作为绘画素材。

## 本轮体验整改

每组问题、连接方式、镜头目标与来源边界见 `reference/step_review.md`。有效释放后的安装先为 pending，固定动画结束才计入进度；「跳过镜头」完成本次已接受连接并返回整船，「撤回一步」可取消尚未结束的连接。切镜头始于松手之后，不改变正在拖动的来源。近景支持返回整船、剖切、重播上一步连接。

钉动画采用交付整船中的真实铁钉几何，沿钉头到钉身推导的原轴线进入源最终位置，属于代表性示意，不承诺精确施工轨迹/完整钉分布。WA1997 明确区分主结构板的跨缝斜穿钉和外护层轻钉。交付模型未含独立的隔舱 L 形铁件和龙骨轻肘材，本轮没有补造这些几何；对应步骤明确说明。不能把普通钉动画当成L形铁件复原，不能把v3互动扩展说成考古原榫。

视觉资源由并行会话提供在 `visual_polish/`，当前实际入口已接入 `bridge_style.gd` 与 `bridge_surface.gd`；辅助 preview.png 只验证样式资源，实际船与连接过程以 review_after 下的截图为准。
